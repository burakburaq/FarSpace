# FarSpace

Space mod for Minecraft 26.3 using Fabric.

## Development

Requires JDK 25. Build the mod with `./gradlew build` (Windows: `gradlew.bat build`). The JAR is created in `build/libs/`. Run the development client with `./gradlew runClient`.
